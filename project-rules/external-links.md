# 外部指向规则

## 适用范围

适用于项目根目录 .link/。全部指向从本项目通向外部对象，包括软件、SSH 配置、其他项目、文件、目录及网址。

## 规则

1. 指向条目统一使用“指向、是什么、本项目用途、使用方式、项目约定”五字段。普通条目的已确认参数写在相应字段内；0 号是固定正文，必须全文匹配模板。
2. system-management 放软件安装与系统管理入口；tools 放具体软件工具；connections 放 SSH 等连接配置；projects 放项目；files 放一般文件和目录；web 放网址资源。按对象实际性质分类，例如远端项目仍归 projects。类别目录按实际条目产生。
3. 编号跨类别唯一，保留已有编号。0 号固定为 system-management/0-system-index.md，精确指向 C:\Sys M\INDEX.md；需要软件或系统工具时优先查阅。另在 .link/ 根层用以版本号命名的空文件标记项目系统版本。这两项已有 yzz 的规范授权。
4. 新的外部对象须先向 yzz 询问，得到目标信息和添加许可后登记。已有明确回答与许可继续适用。现有条目可以维护已确认的用途、参数和使用信息。
5. 指向记录不自动授权修改外部对象、连接 SSH、使用凭据、安装软件或执行其中的命令。必要的具体操作依据本轮实际授权。
6. 不在条目中保存密码、私钥或令牌正文；配置指向可以记录具体配置文件位置、主机别名和获准的使用说明。
7. 项目系统只保留一个空版本文件，名称完整等于所用技能 version.json 的规范版本号，文件内容为零字节。源码与版本变化在 SKILLS 内查阅。
8. 全部部署或更新完成并核对后，才创建目标版本空文件或将旧标记更名。部分完成时在本次交付中说明未完成事项；无旧版本时先按实际内容识别。多个版本标记或文件名相同但有内容时，先核对来源并处理冲突。
9. 普通参考资料的出处在 references 保存；另行登记为外部使用对象时仍需新增指向许可。

## 操作与记录

先读 .link/README.md 和相关条目。登记时选择性质、使用未占用编号、填写五字段并同步索引。修改参数先核对已确认来源。移动条目时保留内容及许可，并更新活动引用。

默认索引访问检查的成功、失败或不可访问情况在本次回复中说明。

本项目补充：无额外约定。
