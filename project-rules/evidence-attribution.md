# 证据与归属规则

## 适用范围

适用于任务理解、决定来源、历史核对及资料使用。

## 规则

1. yzz 原话用于判断其目标、批准、否决和范围；第三方原话只证明第三方提出过相应内容。
2. Agent 的解释、推论、总结和后台写入没有 yzz 的决策权；推论说明依据，外部事实说明来源与适用范围。
3. 按时间读取相关历史，核对后续纠正、否决和范围调整，采用最后一次有效的 yzz 表态。
4. 当前文件受到质疑时回查原始记录，不能以该文件自身作为其来源证明。
5. 保留原始历史。错误中间答案只记录当时发生的事情，不自动成为当前策略。
6. yzz 的经历、设备、能力和认知状态只采用明确自述，不从示例或假设补写。

## 操作与记录

写入前核对陈述、提出者、实际表态、后续变化和来源位置。新编写的归属说明采用 yzz；旧原话中的称呼、拼写和路径保持原样。缺少原始内容如实说明，迁移保留原件和位置映射。

本项目来源约定：会话归档可能跳过被改写分支、工具输出、后台任务和压缩前历史。归档元数据必须与正文一起读取。关键信息缺失时，可以回查本地源 JSONL；不能用 Agent 记忆补全。外部原始资料用于核验外部事实，记录日期、版本和适用范围。对每个准备写入最终策略的承重陈述，另核对批准是否只针对写入、执行、内容或验收中的某一项，以及当前文件是否准确保留归属。
