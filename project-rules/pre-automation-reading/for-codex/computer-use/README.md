# Codex Computer Use 规则

## 适用范围

适用于 Codex 判断本次任务需要通过电脑界面进行操作的情形，覆盖浏览器相关操作与原生桌面应用操作。

## 规则

1. 使用前明确向 yzz 发起交互式问题，说明需要操作的应用或窗口、目的和操作范围。优先使用当前可用的提问工具显示选项，等待 yzz 明确允许后才能开始。
2. 当前没有相应提问工具时，用清楚的问题等待答复。
3. 已经得到的 Computer Use 许可在明确的对象与范围内继续适用，不对同一范围反复询问；对象或范围扩大时重新提问。
4. 获准后读取当前 Computer Use 能力的完整说明，按其实际支持的接口操作。不可用时说明情况。

## 操作与记录

提问示例：“本次需要通过 Computer Use 操作〈应用或窗口〉，完成〈具体动作〉，范围为〈边界〉。是否允许？” 获准前可以继续其他独立、已授权且无需此能力的工作。

记录实际答复及范围。经验和脚本写入上级 for-codex/ 目录，依其 [自动化规则](../README.md) 自动维护。
