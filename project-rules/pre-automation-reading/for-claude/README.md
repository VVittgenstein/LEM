# Claude 自动化规则

## 适用范围

适用于 Claude 在本项目中的浏览器自动化。实际执行使用当前环境可用能力及其文档。

## 规则

1. 浏览器自动化默认使用 Playwright，执行前读取当前可用 Playwright 能力的说明及相关项目经验。
2. 使用实际页面状态与可验证结果操作。
3. 默认工具不可用时说明实际情况，保留未完成状态并提出具体问题。

## 操作与记录

1. 开始自动化前先阅读本目录中与当前任务有关的经验和脚本说明。
2. 自动化中取得可复用经验后，移除经验文件中的空状态说明并自动维护本目录的 experience.md，说明日期、环境或版本、问题、已核实的方法、适用限制及相关脚本。原因未查明或方法未经验证时如实标明。
3. 实际需要建立的可复用脚本保存在本目录 scripts/，说明用途、输入、运行条件和验证情况。只保存当前平台工具允许的脚本。
4. 经验和脚本可以在已授权任务范围内自动维护；规则正文的变动按项目规则批准流程处理。
5. 更新项目系统时保留已积累的经验和脚本。仅在文件缺失时初始化空经验模板。

本平台经验见 [experience.md](experience.md)。脚本只在实际产生时保存到本目录 scripts/；具体调用前阅读说明。
