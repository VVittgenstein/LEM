# 项目规则

本索引的六项共同规则采用固定正文，其他规则按本项目实际需要列在其后。

| 规则类型 | 适用工作 | 文件 |
|---|---|---|
| 文档维护 | 读取与维护项目文件，处理系统部署与更新。 | [document-maintenance.md](document-maintenance.md) |
| 当前任务记录 | 新增获准任务、追加进展、同步索引及整项归档。 | [current-ledger.md](current-ledger.md) |
| 最终策略编写 | 依据 yzz 批准的内容维护最终策略。 | [strategy-writing.md](strategy-writing.md) |
| 外部指向 | 登记、维护和查阅项目向外的指向。 | [external-links.md](external-links.md) |
| 自动化前阅读 | 开始自动化任务前读取对应 Agent 的规则与经验。 | [pre-automation-reading/](pre-automation-reading/README.md) |
| Git 与发布 | 本地版本保护、公开范围、提交署名与推送。 | [git-publication.md](git-publication.md) |
| 权限与批准 | 判断写入授权、执行授权、内容批准与结果验收，核对状态修改前的授权。 | [authority-and-approval.md](authority-and-approval.md) |
| 证据与归属 | 判断原话、批准、否决与范围，按时间核对来源。 | [evidence-attribution.md](evidence-attribution.md) |

Git 与发布规则的配套文件：[public-paths.txt](public-paths.txt)、[public-history-commits.txt](public-history-commits.txt)、[pre-push](pre-push)。
