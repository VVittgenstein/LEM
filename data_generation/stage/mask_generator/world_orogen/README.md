# World Orogen 平面分区与台地选择

本模块将 World Orogen 的分区生成改为 500×500、1 km 格距的平面数据，接入当前对话确认的统一概率选择算法。原始海洋带为外圈 10 格，台地以完整分区为选择单元，50% 至 60% 是软面积目标。

运行入口：

```powershell
& F:\LEM\data_generation\stage\mask_generator\run_world_orogen.ps1
```

默认输出位于 `F:\LEM\output\mask_generator\world_orogen`。使用既有 D 会话的隔离 Python 环境，不安装依赖。默认最多 8 个 Python 进程，包含协调进程；每个进程固定一个 CPU，数值库线程数为 1。

## 分区阶段的改造

1. 在可用平面中放置抖动采样点，建立 Delaunay 邻接图。沿用上游的远点种子选择、每区增长次数、方向偏好、增长抑制和紧凑性控制。
2. 每区轮流扩展到尚未分配的相邻采样点，直至粗网格全部分配。某轮只消耗已有内部边界点时，继续处理剩余边界队列。
3. 按上游方式平滑粗分区标签。连通性整理以分区种子所在部分为保留部分，将其余输入片段重新分配到相邻分区，使每个分区保留真实起点。
4. 用上游 Simplex 实现的四层坐标扰动，查询粗分区归属并映射到 1 km 格网。位移在原种子附近及可用域边缘衰减。首层幅度为粗采样间距乘 `(1.5+lowPlateFactor)×warp_multiplier`。
5. 对栅格化后的分区完成种子连通性整理。所有可用格仍然属于某个分区，分区数量保持不变，重分配数量与比例逐份记录。

分区连通性整理属于台地选择前的输入构造。最终台地掩膜由选中分区直接取并集，不做填洞、删块、平滑或按面积切割。

本轮没有使用上游的内部海域自动吸收，也没有执行上游高程、侵蚀、气候或火山模块。原始代码与适配范围见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 统一的分区选择

初始分区取偏好中心坐标所在的分区。该分区保持选中。后续每一步考虑全部尚未选择的分区，计算加入后整个组合的变化：

- `R`：全部台地到偏好中心的距离平方的面积平均值，再除以 500²。包含分区内部范围以及单格面积贡献，兼顾整体偏移与分散程度。
- `Q`：各连通部分面积占比平方之和，等于从全部台地独立抽取两个位置时属于同一连通部分的概率。

候选评分为 `connection_weight×ΔQ-center_weight×ΔR`，再用 softmax 转为概率。按概率抽取一个完整分区，更新状态并重复。实现采用连通分量合并的增量公式，已与人工小图的完整重算逐项核对。

面积一旦达到本次目标便停止。超过 60% 的结果保留并标注，超过部分最多来自最后一次加入的整分区。相邻或非相邻候选共享同一个公式，未给小岛设单独面积份额或距离阈值。

数值定义与数学验证见 [模型讨论记录](../../../../references/2026-09-11-partition-selection-model/model.md)。本轮是否生成所需的整体轮廓与发生频率，依赖真实分区上的结果检查。

## 四阶段交付

每份样本保存：

```text
partitions_28/seed1001/
  four_stages.png             用户指定的2×2四阶段图，每格面板500×500
  01_seeds.png                原始分区起点与编号
  02_partitions.png           完成分区图与编号
  03_selection.png            选中分区，圆圈标出唯一初始分区
  04_mask.png, mask.png       两色最终掩膜，500×500
  mask.npy                   布尔掩膜
  partitions.npy             分区标签，0为海洋带，1至P为分区编号
  coarse_partitions.npz       粗采样坐标与归属
  projection.npz             实际使用的两轴查询位移，单位km
  regions.json               面积、面积中心、二阶矩与邻接关系
  partition_generation.json  生长参数、种子、分区整理记录和哈希
  selection.json             每一步候选评分、概率、随机数、选择顺序、R、Q及面积
  contours.json              精确格子边缘轮廓，包含全部分离部分与内部轮廓
  config.json                参数、来源与坐标约定
  metrics.json               统一形状统计及选择结果统计
  status.json                数据检查与图像观察状态
  steps/000.png ...          已保存的逐步组合图
```

`comparison.png` 按相同种子排列三个分区数的最终掩膜。`report.html` 汇总四阶段图，并可用滑条查看已保存的选择步骤与候选概率；页面不重新计算随机过程。

NPY 第 0 行对应域底部，格中心为 `(column+0.5,row+0.5)` km。PNG 顶行对应 NPY 最后一行。最终掩膜颜色为台地 RGB=(82,129,200)、其他区域 RGB=(30,30,30)，可无损还原数组。

## 检查范围

代码测试覆盖：与上游一致的 Simplex 固定值；完整分区覆盖、海洋带、种子归属和分区连通性；输入二阶矩；完整重算与增量候选概率的一致性；非邻接候选正概率；软预算、整区加入与可复现性；图片、轮廓和四阶段面板的精确对应。

每份实际样本再次核对图上与栅格上的连通结果、完整分区并集、选择复现、掩膜图片及轮廓还原。超出面积偏好范围不会导致数据检查失败。边带连续接触达到 25 km 时沿用初版的自动提示阈值，该阈值只用于记录。

`distribution.csv/json` 是额外种子的观测计数，不能以 64 个样本确定极小概率。`reference_comparison.json` 展示 34 个真实陆块的原始统计及本轮结果；参考面积范围不同，未将该对照作为分布一致性验收或参数拟合。

自然外观按实际图片另行记录，用户验收状态保持独立。本地 HTML 的静态文件与数据对应关系会核对；浏览器工具此前阻止 file URL 访问，本轮不将浏览器交互列为已完成验证。

## 首轮观测与追加对照

基准 192 份诊断中，14、28、56 分区各 64 个种子生成单一连通块的数量分别为 60、44、21。相同的权重在不同分区数下产生了不同的连通结果频率。

因此，本轮又保留相同的 56 分区几何、种子和目标占比，增加位置权重 96、成片权重 32 的一组工程对照，生成 6 份四阶段样本和 64 份统计。该组单一连通块为 35/64，三个及以上连通块为 2/64。它没有被选定为最终配置。

```powershell
& F:\LEM\docs\work\2026-09-08-q1-data\D-landform-statistics\.venv\Scripts\python.exe -B -u F:\LEM\data_generation\stage\mask_generator\run_world_orogen.py --stage all --workers 8 --partition-counts 56 --center-weight 96 --connection-weight 32 --output F:\LEM\output\mask_generator\world_orogen\weight_comparison_96_32
```

四阶段可视样本合计 24 份，额外诊断合计 256 份。基准输出与追加对照分开保存。

图像检查仍发现海洋带内缘的长直边。基准 14 和 28 分区的 12 份展示样本中，全部不触边分区的总面积都不足本次停止目标；以整分区达到目标时必然包含触边分区。该诊断保存在 `metrics.json` 的 `boundary_region_ids` 和 `interior_only_available_fraction` 中。56 分区中存在不触边面积充足的样本，但当前概率规则仍可能选到边缘分区。边界几何与实际分布范围仍需后续讨论和检查。
