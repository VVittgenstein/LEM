# 水下台地整组概率选择

本模块生成 500×500、1 km 格距的二维布尔掩膜。选择单元为 World Orogen 平面改造后的完整分区。外围禁选层数由 `boundary_layers` 设置：触及边界为第1层，共享边界的相邻分区逐层向内计数。中心分区只用于一条抽样链的初始化，之后可以取消选择。

当前采用 **512分区、外围3层禁选**。该形状配置已由用户选定，决策原文与对应样本见 [SELECTED_PROFILE.md](SELECTED_PROFILE.md)。其余参数沿用所选批次。

## 运行与文件

在 PowerShell 中运行：

默认入口只生成512分区、外围3层禁选的一组六个种子，依次执行代码测试、生成、报告和数据审计：

```powershell
& F:\LEM\data_generation\stage\mask_generator\run_world_orogen_gibbs.ps1
```

也可以分阶段运行：

```powershell
& F:\LEM\data_generation\stage\mask_generator\run_world_orogen_gibbs.ps1 -Stage test
& F:\LEM\data_generation\stage\mask_generator\run_world_orogen_gibbs.ps1 -Stage generate
& F:\LEM\data_generation\stage\mask_generator\run_world_orogen_gibbs.ps1 -Stage report
& F:\LEM\data_generation\stage\mask_generator\run_world_orogen_gibbs.ps1 -Stage audit
```

默认读取本模块的 `experiment.json`，在输出目录保存副本 `selected_settings.json`。默认输出为 `F:\LEM\output\mask_generator\world_orogen_gibbs_512_layers_3`。指定另一个 `-Output` 可以复现到新的目录；重复运行相同输出会重写对应产物。分区与随机场输入参数发生变化时，缓存检查要求使用不同输出目录。

`run_world_orogen_gibbs.py` 支持 `--partition-counts`、`--seeds`、`--burn`、`--draws`、`--thin`。`--stage pilot` 重跑三组工程试验；`--stage diagnose` 将独立试验种子写入 `diagnostic/`，不会混入正式四阶段样本目录。

PowerShell入口支持 `-PartitionCounts` 和 `-BoundaryLayers` 显式对照。自动输出目录同时包含分区数和层数，例如 `world_orogen_gibbs_256_512_1024_layers_4`，避免与已有历史对照目录混用。

使用 D 会话已有 Python 环境。`Sampler.cs` 由机器已有 `.NET Framework` 编译器编译到本模块 `bin/`。不安装依赖，不修改 lem-env。最多三个 Python 工作进程，每个进程至多一个 C# 子进程，含协调进程共七个；每个工作进程及其子进程共用一个 CPU，数值库单线程。`--workers` 控制整个任务的进程预算，至少需要两个进程才能启动外部抽样内核。

## 完整概率定义

令 `S` 为被选中的分区集合。允许状态为所有可选分区的非空子集。禁选分区永远为零，中心分区无特殊约束。面积空集合没有面积中心，且无法用作台地样本，因此从状态空间排除。

所有位置坐标先除以 500 km，并以域中心为原点；单格二阶矩包含方格内部的 `1/(6×500²)` 贡献。

| 记号 | 定义与归一化 |
| --- | --- |
| `f` | 选区面积除以整个域的 250000 km² |
| `C` | 整组面积中心到域中心的距离平方，除以 500² km² |
| `R` | 选区绕自身面积中心的面积平均距离平方，除以 500² km² |
| `P` | 选中与未选中区域间的所有格子边界长度，除以 500 km；包含闭孔边界 |
| `F` | 选中区域内组合随机场的面积积分，除以 250000 km² |
| `d` | `max(0.50-f, 0, f-0.60)` |

当前评分为：

```text
E(S | g) = 60 × 0.5 × (d / 0.12)²
           + 5000 × C + 1600 × R + 15 × P - 600 × F
p(S | g) = exp(-E / T) / 所有允许状态的 exp(-E / T) 之和
目标温度 T = 1
```

这些系数为工程试验值。50% 至 60% 区间内部的面积项均为零。区间外为有限连续惩罚，没有达到某个面积才能结束的判断。面积偏好不保证最终平均面积落在偏好区间。不同面积下状态数量及其他评分都会影响实际分布。

一次输出先从固定场模型抽取 `g`，再从 `p(S | g)` 抽取分区状态。因此批量分布同时包含随机场和分区状态两种随机性。评分没有地质物理能量含义，未把本模型当成真实地台形成过程。

## 空间随机场

三张独立标准正态底图分别用标准差为 15、45、120 km 的高斯核平滑。每张底图包含超过四个标准差的外围填充；中央区域不受滤波边界影响。中央 500×500 数值分别减均值、除标准差，再以 0.30、0.85、0.65 加权相加，组合场再次标准化。

每个分区取组合场的面积平均值。三档分区在相同种子下使用完全相同的像元随机场，分区平均值随分区几何变化。随机场在一张图的所有链与温度更新中保持不变。尺度指高斯核标准差，与旧方案中的方形平均窗口边长有不同定义。

## 分区与边界

采用只读依赖 `world_orogen.partitions.grow_partitions` 和 `world_orogen.noise`。在完整域内建立 160×160 抖动采样点，按 World Orogen 方式生成分区，使用四层 Simplex 查询位移投影到最终格网。

分区栅格化之后，以各分区种子所在连通部分为起点，重新分配输入分区的离散片段。此时尚未选择台地。所有像元仍有分区归属，各分区保持四连通。外侧行列接触到的完整分区随后全部禁选，海域宽度由这些分区的几何决定。最终 mask 直接由选中分区取并集，没有填洞、补连接或删除小块。

## 抽样与复现

对于分区 `i`，完整评分在不选和选中时分别为 `E0`、`E1`。条件概率为 `sigmoid((E0-E1)/T)`，按此概率抽取新的零或一状态。增量更新同时维护面积、一阶矩、二阶矩、边界长度和场积分，并周期性完整重算以控制浮点误差。

四条独立链分别采用中心分区、全部可选分区、随机组合和居中组合初始化。每条链含十四个温度槽位，温度为 `1.18^k, k=0..13`。每四轮尝试相邻温度交换，交换接受概率由完整评分计算，目标温度仍为一。最终一轮只作 Gibbs 更新，便于保存可逐步还原的完整记录；这一步保留同一目标分布。

正式样本每链预热 4096 轮，此后每四轮记录一次，共 2048 个状态。最终代表图固定取第零条链的最后一个记录状态。没有按外观、面积或评分挑选代表图。

随机源：World Orogen 的 Park-Miller 和 Simplex 沿用前次改造；场使用 `SeedSequence([seed,420,scale_index])`；抽样内核使用 PCG32，链种子为 `(seed+810000)+chain×1000003`，按 32 位无符号整数回绕。内核源码和二进制哈希随产物保存。

## 验证与诊断

小图验证枚举九个可选分区的 511 个非空状态，比较精确概率与带温度交换的实际抽样。逐分区条件概率、完整评分与增量更新、中心取消、整区禁选和重复运行均有代码检查。

真实分区的每个固定随机场单独进行链间比较，采用秩归一化 split/folded R-hat、bulk ESS，并检查每个可变分区的占据状态。当前工程判据为 R-hat≤1.05、全局量 bulk ESS≥100。相同状态常量单独记录；这些有限样本诊断不能证明已经完全收敛。不同随机场对应不同目标分布，不混在一起计算 R-hat。

台地统计包括最大与第二大连通部分、全部连通块面积、面积中心、分散尺度、完整边界长度和闭孔。半径 5、10、20 km 的形态开运算只用于窄连接的几何诊断，结果不替代掩膜，也未把它当成已定义的五类判别器。

每份结果保存 `four_stages.png`、四张 500×500 阶段图、原尺寸 `mask.png` 和 `mask.npy`、轮廓、分区数组、完整编号放大图、随机场、整组评分、条件概率、抽样状态、更新记录和诊断。NPY 第一行在域底部，PNG 顶行对应 NPY 最后一行。

## 2.0 批次结果与限制

已生成三档分区、六个共同种子的 18 份四阶段样本。32 个额外种子采用 512 分区、相同参数，使用每链 1024 轮预热、512 个记录状态、每四轮记录一次的安排；所有额外样本逐一通过同样的诊断判据。

正式样本的面积为 39.60% 至 47.91%。额外样本的面积为 38.74% 至 47.94%，中位为 45.26%。面积偏好项已按区间内同等、区间外有限代价实现，当前参数的整体输出仍偏向较小面积。

额外 32 个样本中，31 个最大连通部分占台地至少 90%；1 个第二大部分占台地至少 10%。这些百分比只是描述统计的分界，未作为生成规则或五类判别标准。多主体与高度碎化这一端尚未得到充分展示。

1024 分区的六个正式样本包含 13 至 26 个连通部分，多数新增部分面积较小。这说明固定评分系数下，分区精度会影响离散状态的组合数量与单步条件概率。当前没有把不同分区精度的输出当成同一形态分布，也没有通过删除小块改变结果。

输入边界问题已通过完整触边分区禁选处理。图像、数组、全部轮廓及保存的抽样状态分别核查。用户外观验收和五种结构的频率验收仍待后续讨论。

## 2.1 外围预留层数

根据后续讨论，预留区还需要为浅海、深海、过渡坡面和演化提供空间。此轮按用户指定比较外围 3、5、10 层，逐层关系采用共享像元边界的分区邻接图。每一层由到外边界的最短邻接路径确定，接触角点不计为邻接。每个分区始终整块排除。

同一层数对应的实际宽度随分区大小、形状和数量变化。程序同时记录每个分区的层号、到数据域边界的最小距离，以及剩余可选面积。距离以1 km方格的边缘计算。可选区为空时直接报告，没有自动减少层数。

```powershell

```

输出目录为 `output/mask_generator/world_orogen_boundary_layers/`，包含18张输入分区图在三档层数下的54组对照。旧台地结果保持原样。
