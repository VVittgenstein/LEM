# 随机入场窗口与ABCD展示

[8组图集](output/gallery.html) · [32张PNG](output/eight_ABCD_png.zip) · [32张SVG](output/eight_ABCD_svg.zip) · [检查结果](checks/audit.json)

本阶段工作及产物全部位于`F:\LEM\data_generation\stage\convergent_uplift\window_pipeline`。输入为此前生成的完整汇聚抬升场，输出为随机放置的500×500 km窗口、1 km网格U数组、独立生成的台地与初始海底底图，以及每样本4张图片。

## 用户要求与实现

- 位置、进入方向、相对旋转角度及移动深度随机。
- 截入数据域的全部辅助线片段在数据域自身X或Y方向的投影跨度至少150 km。先裁剪，再取坐标最大值与最小值。
- 至少有一侧在台地内部自然归零，允许侧翼或端部满足。轴线可只进入台地局部，其他方向的场可以延伸出台地。
- 余量采用实际几何值作为偏好，不设固定公里数门槛。
- 重叠面积不参与准入或抽取权重。输出面积仅作记录。
- 粉色半透明掩膜表示台地与截取后非零抬升作用范围的交集。

## 输入底图

`prepare.py`将原台地、深浅海分配、初始海底代码复制到vendor，保留来源与逐文件哈希。`base_worker.py`在本目录重新运行8个种子，采用原512分区、外围3层禁选、Gibbs设置，使用已验收的95 km口径海域分配函数和固定海底参数。来源参数没有重新拟合。

8份台地的抽样诊断均通过。种子1001至1006与先前同种子的台地和高程结果逐数组比较；结果见各bases/seed*/metadata.json。种子1007和1008由相同管线新生成。所有新输出与编译内核保存在本模块。

基础高程是相对初始海平面的m值；U数组使用m/yr，图片U色标使用mm/yr。图D以原始高程绘制底图和等高线，U作为独立图层。

## 边界入场与候选

完整场的实际作用区域采用已保存1 km正值单元的方格并集。沿各外边界按弧长等概率选取参照点；进入方向在局部向内方向两侧各65度范围内均匀抽取，窗口角度在0至360度均匀抽取。

每条轨迹经过该参照点。利用完整场在进入方向的投影包络及旋转正方形的半径，构造一个保证整块窗口位于场外的起点和另一侧终点。移动距离从这个场外起点量起。多个分支可沿同一轨迹依次进入窗口；参照点不要求是旋转正方形首次接触场的唯一接触点。

每条轨迹在移动范围内分层随机抽取24个距离，按距离顺序检查。正式每个种子使用160条轨迹，共3,840个候选；若某批没有可验证结果，可以按固定规则继续新的轨迹块，最多4批。本次8个样本均在首批找到结果。

进入方向范围、候选数量和软权重是本版实现设置，未解释为地学观测分布。候选参数、拒绝原因、随机流和被选编号均保存。

## 一侧归零的验证

本版把要求落实为一条可检查的完整单侧剖面：起点位于台地内的辅助线上，沿该方向可以到达台地内的真实零值边界，连接线段全部位于台地内部。候选还须存在一段正长度的原场自然边界位于台地内，避免以孤立相切点作为依据。

先在原完整场的自然边界中提出验证位置，再调用原连续抬升函数，在剖面上找到首次严格U=0的位置。该位置后方的短距离探针也必须为零。验证使用原场边界，窗口裁切形成的边缘不作为归零依据。图D白色圆点和虚线标出这一剖面及归零点。

快速提议阶段最多检查6条较长的台地内边界片段，并检查每段的中点和两个四分位位置。这是有限候选搜索，未声称枚举所有可行布局。最终归零判定由原连续函数完成。

图中报告的余量，是这个选定归零点到最近台地边界的距离。它不表示整条活动带所有边界的最小余量。其他部分的位置另外记录，不要求整个作用范围包含于台地。

## 随机选择与软偏好

通过准入的候选采用加权随机抽取。权重为`exp(4*r_axis + 1.5*r_zero + 1.5*r_margin)`：

- `r_axis`为已截取辅助线中位于台地内的弧长比例。这一比例只用于位置偏好；150 km准入门槛始终使用坐标跨度。
- `r_zero`为窗口内原场自然归零边界中位于台地内的长度比例。
- `r_margin`为验证位置的余量除以该台地的最大内部距离，并限于0至1。

每个种子分别固定候选随机流与选择随机流。按概率选中后进行连续场精确验证；如未通过，保留原因并在剩余候选中继续加权抽取。没有按外观更换正式种子或补充形态类别。

## 坐标与U值

窗口采用刚体平移与旋转。局部坐标为0至500 km，格心为0.5至499.5 km。正交旋转矩阵将D图坐标映射回完整场坐标；C图红框由这同一变换生成。

D的每个格点在原连续抬升函数上取值，使用原场保存的峰值、宽度、形状参数及缩放结果。台地用于位置偏好和交集显示，U值保持原函数定义。窗口边缘可以有非零U。裁取中没有缩放活动尺度、归一化速率或把速率加到初始高程。

## 文件与重现

- `output/seed*/selection.json`：坐标变换、抽取结果、跨度、权重、真实归零验证及来源哈希。
- `entry_paths.json`、`candidates.csv`：全部随机轨迹和候选记录。
- `window.npz`：U、作用mask、粉色交集、台地mask及初始高程。
- `display_geometry.json`：四图尺寸、坐标变换、色标及掩膜定义。
- `bases/`：复制管线生成的8份完整底图数据、台地抽样及诊断。
- `inputs/manifest.json`：代码副本、固定参数及只读完整场来源。
- `checks/tests.json`、`audit.json`、`reproducibility.json`：数值检查及完整选择重跑。

从父目录运行`run_windows.ps1`。默认包含准备、底图、采样、绘图、核查和打包；可指定prepare、bases、generate、render、validate或finish阶段。已有底图缓存按其文件身份和参数哈希读取。

8项测试覆盖刚体坐标、投影跨度、片段合并、取消面积门槛、自然边界识别、掩膜几何、原函数回读和随机流。每份正式样本另外核查红框500 km、跨度、一侧真实归零、粉色交集、图幅、SVG路径和格点U回算。种子1006进行了完整候选生成与数组重跑。
