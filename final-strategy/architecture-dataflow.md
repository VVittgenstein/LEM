## 1. 模型层级

### 1.1 L1 结构层

- 模型类型：无条件扩散模型。
- 部署角色：一个 L1 结构层。验证阶段依次训练两个 L1 模型版本。
- 输入和输出尺寸：500×500 像素。
- 空间分辨率：1km/px。
- 地理范围：500km×500km。
- 当前样本目标：完整包含大陆及海域，外围海洋、内部陆地可不连续且不必居中，允许内海；海岸、内陆、山地、水系等组织共同处于样本内。单个大陆内部尽可能呈现真实感、丰富环境变化和宏伟山峰、低谷、海岸等特殊点，同时保持自然性及区域尺度。具体含义见 `product-and-boundaries.md` 第 1.1、1.2、2.1 节。2026-09-09 特殊点与记忆点的要求退出 MVP，见产品文件第 1.2 节。
- 第一个 L1：只生成高程。
- 第二个 L1：联合生成高程和汇水面积。
- 第二个 L1 通过验证后，L1 输出包含粗分辨率高程与汇水面积；大尺度干流和流域结构通过这两个通道的关系进行验证。

### 1.2 L2 条件精化模型族

适用范围：后续方案，当前不开展 L2 调查、数据生成或训练。

- 模型类型：条件扩散模型。
- 数量：一个或多个子级，例如 L2-0、L2-1。
- 每个模型的输入和输出尺寸：500×500 像素。
- 既有后续分辨率序列：1km 到 100m，再到 10m。
- 输出：高程、水文和其他已纳入数据格式的地貌通道。

### 1.3 L3 真实数据细节层

- 模型类型：条件超分模型。
- 分辨率范围：约 10m 到 1m。
- 训练数据：真实 DEM 或 LiDAR。
- MVP 状态：不包含。10m 到 1m 的既有转换安排保留为后续方案，当前 L1 到 Minecraft 的具体尺度转换仍需确定。

### 1.4 方块化层

- 类型：确定性规则代码。
- 输入：模型输出的高程和其他通道。
- 输出：Minecraft 方块、群系参数和其他游戏数据。
- 该层不需要模型训练。

当前 MVP 的模型范围为 L1，依次验证高程与高程加汇水面积两个版本。L2/L3 保留后续身份。

## 2. 模型关系

当前 L1 独立训练和推理。以下层级关系保留为后续方案：每个层级使用独立模型、独立权重和独立去噪循环；训练阶段各层可以独立进行，推理阶段按 L1、L2-0、L2-1 的顺序执行，上一级结果作为下一级条件。

“统一模型部署”用于区分教师模型和部署模型：

1. 教师模型只存在于训练阶段，不部署。
2. 每个层级在服务器在线生成、预生成和其他部署场景中使用同一版本的蒸馏后模型。
3. L1、L2-0 和 L2-1 仍是不同模型。
4. 教师模型具体优化指标没有得到 yZz 指定，最终策略不补充该指标。

## 3. 数据通道与参数边界

### 3.1 当前生成通道顺序

1. 第一个 L1 使用 `elevation`，即高程。
2. 第二个 L1 使用 `elevation + drainage_area`，即高程与汇水面积。
3. “水文”是上位类别，当前第一项水文生成通道具体指汇水面积。
4. 后续 L2 方案使用通过 L1 阶段验证并写入 L2 数据契约的生成通道，当前不开展该契约的研究与数据生产。
5. 其他生成通道尚未确定，当前新增通道需要验证 L1 数据与模型关系；下采样及级联验证在后续 L2 范围中开展。

通道与层级是两个独立维度。第二个 L1 输出 1km 格距的高程与汇水面积，用于当前联合生成验证。通过条件链传递给 L2 属于后续方案，其对内流盆地等具体问题的效果尚未验证。

### 3.3 通道契约

所有进入同一模型的数据通道必须定义：

- 单位。
- 数值范围、变换和归一化。
- 空间分辨率。
- 缺失值处理。
- 下采样规则。
- 损失与通道权重。
- 独立评价指标和跨通道一致性指标。
- 文件格式和版本。

#### 4.1.3 真实性的三个概念与衔接规则

三个概念作为数据生成方法的判定框架，定义与边界采用 [`AGENTS.md` 沟通规则第 4 条](../AGENTS.md#沟通规则)；本次定义澄清的来源见 [2026-09-17 用户表态](sources.md#realism-definitions-20260917)。

| 概念 | 含义 | 项目要求 |
|---|---|---|
| 历史真实 | 某段地质历史是否实际发生过。 | 不要求对应真实地点或重建其实际历史。 |
| 过程真实 | 地形是否由适用于当前状态的侵蚀、输运、沉积等过程计算，计算是否可靠。 | 需要，由 LEM 承担。 |
| 地学合理 | 生成的地形与地质活动符合对自然地质现象的常识认知，避免过于巧合或明显反常的形态、数量和组合，即使这些情况在物理上可能发生。 | 需要。 |

允许设计形成地形的条件，并要求地形对这些条件的响应具有物理依据，不要求模拟这些条件在地球内部怎样产生。可以先用一组条件生成陆地，再用另一组条件在其上生成多样化的地貌，衔接必须符合自然界的物理规律：每个阶段自身合理，从上一阶段转到下一阶段也必须是地球条件下可能发生的变化，不能把几种单独看起来合理的过程随便串起来。yZz 的例子：上层 500 米易侵蚀岩层只被削去 50 米、期间没有断层或其他改变材料的过程时，后续不能改用下层抗蚀岩石的侵蚀参数。参数的数值范围与空间分布分别论证（Codex 解释，yZz 随后以三个概念吸收）。

例如，自然形成的规则正方形大陆显得过于巧合；在 500 km × 500 km 的区域内密集出现一百个汇聚带，即使物理上可能，也明显偏离常识认知。这些情况即使采用可靠的过程计算，仍可能不满足地学合理。

数据用于训练去噪模型；模型学到的是符合过程真实与地学合理的地形长什么样子（yZz 2026-09-07 确认）。演化过程本身不进入训练数据，终态由初始状态、驱动条件、过程计算与作用时长共同决定，生成方法需要先对条件、过程和衔接的合理性负责。

#### 4.1.4 任务定义与交付边界：数据与参数生成管线（原问题 1）

任务定义（yZz 2026-09-09 批准）：建立一条有依据、可自动执行的数据与参数生成管线，把五类数据变成 Fastscape 的输入，即初始高程与海平面、随时间变化的抬升数组、K、D 与降水数组及全局参数、边界；每份样本运行到抽定的模拟时长 T，输出 500×500、1 km 格距的高程，经统计检验后成为 L1 训练样本；同时交付依据说明，每条依据标明四种状态之一。管线覆盖 1A 定义中的“完整方法”。

范围内：五类数据及其补齐，含交给 Codex 的前置任务与 Claude 主线的工作线 A、C、D；生成器；驱动；校准；检验；测试运行，测试阶段约束为 8 个独立样本并行、每样本 1 核、单样本完整实际用时不超过 180 秒；生产阶段的用时预算由 T 决定。范围外：正式生产训练集，为 1A 的后续任务；1A 包含用该管线生产一定数量的示例数据（yZz 2026-09-09）。

验收里程碑：里程碑1为海陆组织，包含初始条件、实际演化结果、边界与统计依据。初始水下台地二维形状采用第4.1.5节选定的512分区、外围3层禁选方案；50%至60%为面积偏好，34个参考陆块提供形状参考。T时刻的外围海洋与陆地不触界要求继续单独检验，初始掩膜的选择不构成终态验证。里程碑2为陆地内容，地貌家族、区域尺度与空间关系的检验统计量及依据待对应阶段确定；群系不在高程数据内。里程碑3为示例数据，数量与完整方法验收仍按1A任务推进。原问题4由地学合理与过程真实承担，原问题6已经撤销。

分工：独立前置任务与主线分别记录各自的数据获取、计算、检索、汇总、研发和运行范围。当前执行对象、责任范围和授权来源见 `current.md` T-010。

以下为 2026-09-07 的原始定义与交付边界，作为里程碑 1 的依据保留。

yZz 2026-09-07 的定义：在 500 km×500 km 的完整数据域内，从文献、研究和项目中寻找，或通过借鉴、合成、改造获得一套有依据的参数空间分配方法：明确哪些格子赋予什么抬升、侵蚀和输运等条件，为什么这样分配，以及允许怎样随机变化，使其能够批量生成满足过程真实、地学合理和既定海陆组织要求的环海大陆。“哪些格子给什么、怎么计算”是必须交付的具体方法，“为什么能这样给、生成结果为什么可以接受、方法从哪里来”是方法必须回答的依据与约束，两者同等重要。

阶段结果的保存与结束（yZz 2026-09-07 提出）：计算海平面以上面积与数据域面积的比例；陆地比例达到 50%、55%、60% 时各保存一次；比例的变化速率用于研究结束规则，速率阈值由实际运行判断。面积比例加变化率的规则用于产生群岛、带内海的大陆、大陆等不同的陆地形态。Codex 对“同一次运行首次达到各比例时保存”的理解和变化率取绝对值、按物理时间、持续窗口的细节属于实现解释，未获单独确认。2026-09-09 yZz 改定（归档消息 150）：每份样本抽一个模拟时长 T，活动时间表按 T 生成，运行到 T 结束，不设指标型结束条件；理由是指标型结束与原则冲突，GPT 的实验显示等待面积变化率降低会使陆地比例从 60% 推到 80%；T 的范围由建起地形所需时间与活动持续时间约束，数量级 5 至 30 Myr，比 T 长的活动只出现其中一段。据此，50%、55%、60% 保存节点与变化率结束规则不再使用，陆地比例与变化率可作为诊断量记录；实际生成的用时由 T 与步长决定。

#### 4.1.5 当前生成方法框架

总体方法为依据研究与数据确定参数，再通过LEM产生地形，不要求重演历史地质过程。形状环节按下文已选方案执行。以下三类按资料属性划分，来自2026-09-07至09-08的讨论；第1至5类数据需求另按管线用途组织：

| 输入 | 内容 | 依据来源 |
|---|---|---|
| 第一类 | 海底高程与海平面 | 海域组成由参考数据拟合的随机函数确定；基准高程、起伏强度与坡面采用当前固定参数；海平面采用按年代接续的单一重建曲线。具体数据、单位、输入输出与已验收实现见下方四阶段说明。 |
| 第二类 | 给哪些格子分配哪些抬升、沉降等条件，以及何时 | 最复杂的一类。先构建会用到的地质活动类型，建立地质活动清单，清单包含每种活动对应研究给出的数值范围；可能存在关于大陆构型和环海大陆外貌的统计数据，有统计数据后仍需根据关系判断数值的分配。 |
| 第三类 | K、D、U 等过程参数 | 纯粹的研究结果，来自现有对地质、地貌的研究成果，一般形态是一个范围；参数之间有关系，不能真正独立随机。 |

每份样本的生成步骤按输入依赖组织如下。2026-09-12，yZz确认数据4与数据1完成并要求更新项目文档。当前已验收输入由台地掩膜、海域类型分配、初始海底高程和单一海平面曲线四个阶段组成；地质活动、过程参数、放置关系及统一LEM驱动接入继续按后续阶段复核。来源见 [本轮决定与验收](sources.md#input-stages-20260912)。

1. 生成初始水下台地的二维区域掩膜：在500×500、1 km格距的数据域内，以World Orogen平面算法生成512个完整分区，再用整组选区Gibbs方法抽样。外围3层分区禁选，输出布尔掩膜、全部轮廓、参数和统计。规则及实现入口见下方“水下台地二维形状”。
2. 依据掩膜及同一组完整分区生成深浅海标签，按固定剖面与空间相关起伏构造初始水下高程，并从单一年代海平面曲线取得覆盖模拟时长T的时间表。台地、浅海、深海的基础高程分别为−53、−453、−3746 m，相对模拟初始海平面0 m。当前规则和来源见下方“第4类与第1类输入的已验收四阶段”；旧150 km分类、逐样本抽深度及长期与短期海平面叠加、循环的用法保留在原始历史中。
3. 第二类按活动类型逐类形成时间驱动输入。当前非火山类型为汇聚带抬升、裂谷作用、盆地沉降、区域性升降／造陆运动、走滑错动。汇聚事件采用本节已验收的独立事件生成、窗口和时间规则；其余活动的资料与实现按各自讨论推进。跨类型叠加、构造历史影响和整体边界衔接由第五类及统一LEM驱动验证，当前汇聚模块验收不扩展到这些对象。2026-09-09前置任务G、H的原始统计与当时采用方式继续保存在来源第46条及私有资料中。
4. 按第三类输入计算每个格子的参数，写成 Fastscape 的数组：初始高程数组、每个时间步的抬升数组、K 与 D 数组，以及海平面和降水的时间表。按 C 会话核对的 fastscapelib-fortran 接口，K 与 D 为逐格数组，降水为逐格数组并可随时间变化，m、n、G、沉积物的 K 与 D、海洋模块参数为全局标量，一份样本一个值。K 与 D 数组的空间分区由活动类型 9 岩性差异给出，岩层出露时按 E-068 至 E-070 更新；降水数组由活动类型 8 给出；m 与 n 联合抽取使 θ = m/n 落在观测区间，U 与 K 联合抽取使起伏落在所选类型的范围（Claude 说明，yZz 2026-09-09 未提出异议）。海洋模块的配置整组取 Glerum 2024 的参数设定并显式记录 p1、p2：(kds1, kds2) 为 (120,40)、(210,70)、(300,100) m²/yr 三组之一，r = 0.5，p1 = p2 = 0，L = 1000 m（yZz 2026-09-09 同意；来源直接给出的模型设定，不是天然校准，工作线 C 完成前作为假设配置）。
5. 送入LEM运行到抽定的模拟时长T，交付T时刻地形；按既有要求检验外围海洋带和陆地不触界，并对终态地形进行统计比较。初始台地掩膜偏离50%至60%不构成作废条件。当前选定形状的独立实现尚未完成与旧主线的接入和新一轮端到端核验。

## 6. 训练数据生成

该阶段使用 LEM，不使用训练后的模型生产数据族。

1. `data1000m` 先进行小批量生成，验证方法及参数配置。验证通过后按该方法执行 N 次 500km×500km、1km 格距模拟及所选辅助操作，每次形成 500×500 图。
2. `data1000m` 的第一个版本保存高程生成通道，第二个版本保存来自同次模拟的高程和汇水面积生成通道。使用辅助操作时，记录模拟输出到训练通道的处理关系，并验证处理后的跨通道一致性。
3. 方法版本、辅助操作、K、D 和其他 LEM 参数与随机种子、初始条件、边界条件、模拟时间及软件版本一起保存为生成元数据，不进入训练张量。

以下第 4 至 7 项适用于后续 L2 方案，当前暂不开展。两个 L1 阶段通过不自动启动这些步骤。

4. 后续范围恢复并获执行授权后，先小批量生成并验证 `data10m`。既有方案在两个 L1 阶段及跨尺度假设通过后，执行 M 次 50km×50km、10m 格距模拟及所选辅助操作，每次形成 5000×5000@10m 母图。
5. 对每张 `data10m` 母图分别执行两次独立下采样：
   - 生成 500×500@100m 的 `data10mds10`。
   - 生成 50×50@1km 的 `data10mds100`。
6. 两次下采样都直接以 `data10m` 母图为输入，不采用链式下采样。
7. 高程与汇水面积分别定义下采样规则。具体算法与判定标准需要单独批准。

## 7. L1 训练

训练数据只使用 `data1000m` 中当前模型版本要求的生成通道。

训练顺序：

1. 训练只有高程的 L1，并验证当前方法生成的数据能否支持符合真实地形要求的高程生成。
2. 第一个 L1 通过后，训练联合生成高程和汇水面积的 L1，并验证各通道指标和跨通道一致性。
3. 两个 L1 阶段均通过后形成当前 L1 验证结果。后续 L2 母数据生产仍需恢复相应范围并获得执行授权。

每轮训练：

1. 随机抽取一张 `data1000m`。
2. 随机抽取一个噪声强度。抽取范围覆盖从轻微污染到接近完全噪声的全部强度。
3. 按噪声强度向当前生成通道加入具体噪声。
4. 把带噪图输入 L1。
5. 模型预测各生成通道中加入的噪声。
6. 将预测噪声与实际加入的噪声比较并计算训练损失。

训练数据中不包含 K、D、其他 LEM 参数、世界 seed、游戏坐标或运行时 hash 噪声。

## 8. L1 推理

当前生成对象为一份 500 km×500 km 的完整有限海洋大陆。以下随机输入用于该完整域的可复现生成；请求坐标的保留不意味着通过相邻窗口扩展为无限大陆。

1. 输入世界 seed、层级标识和请求坐标。
2. 噪声生成器根据 `(seed, 坐标, L1)` 生成确定的 500×500 起始噪声。
3. L1 执行完整去噪循环。
4. 高程 L1 输出 500×500@1km 高程图；联合 L1 输出同尺寸的高程和汇水面积图。

L1 推理不接收 K、D 或其他 LEM 参数。采样器采用确定性过程；采样步骤需要额外噪声时，所有噪声都由可复现的坐标寻址规则生成。

## 9. L2-0 训练

适用范围：后续 L2 方案，当前暂不开展。

训练数据使用同一编号的 `data10mds10` 与 `data10mds100`。

每轮训练：

1. 取得一张 500×500@100m 的 `data10mds10`。
2. 取得同一编号的 50×50@1km `data10mds100`。
3. 把 `data10mds100` 放大 10 倍到 500×500。放大只对齐像素尺寸，不生成新的地理信息。
4. 给 `data10mds10` 加入噪声；放大后的 `data10mds100` 保持干净。
5. 把带噪细图与干净粗条件沿通道维度组合后输入模型。
6. 模型预测加入细图的噪声并计算训练损失。

## 10. L2-0 推理

适用范围：后续 L2 方案，当前暂不开展。

1. 从 L1 的 500×500@1km 输出中裁出 50×50 区域。该区域覆盖 50km×50km。
2. 把裁出的粗图放大 10 倍到 500×500。
3. 根据 `(seed, 坐标, L2-0)` 生成独立的 500×500 起始噪声。
4. 把起始噪声与粗条件沿通道维度组合。
5. L2-0 执行完整去噪循环，输出 500×500@100m 多通道图。

覆盖完整 500km×500km L1 区域需要 100 个 L2-0 窗口。

## 11. L2-1 训练

适用范围：后续 L2 方案，当前暂不开展。

训练数据使用同一编号的 `data10m` 与 `data10mds10`。

每轮训练：

1. 从 `data10m` 裁出 500×500@10m 窗口。该窗口覆盖 5km×5km。
2. 从同一编号的 `data10mds10` 取得对应的 50×50@100m 区域。
3. 把 100m 粗条件放大到 500×500。
4. 给 10m 细图加入噪声，100m 粗条件保持干净。
5. 沿通道维度组合后输入 L2-1。
6. 模型预测加入细图的噪声并计算训练损失。

## 12. L2-1 推理

适用范围：后续 L2 方案，当前暂不开展。

1. 从 L2-0 的 500×500@100m 输出中裁出 50×50 区域。该区域覆盖 5km×5km。
2. 把粗条件放大到 500×500。
3. 根据 `(seed, 坐标, L2-1)` 生成独立起始噪声。
4. L2-1 执行完整去噪循环。
5. 输出 500×500@10m 多通道图。

## 13. 数据流约束

当前适用 L1 的训练、推理与参数边界。涉及 L2 裁块、下采样和级联的规则适用于后续方案。

1. 下采样只发生在训练数据生成阶段。
2. 模型训练阶段不执行数据族之间的新增下采样。
3. 推理阶段使用裁块和放大，不执行下采样。
4. 每级模型处理 500×500 像素；地理范围依次为 500km、50km 和 5km。
5. L1 训练给目标通道加噪并预测加入的噪声；各 L2 子级给目标细图加噪，粗条件保持干净，模型预测细图中加入的噪声。
6. L1 推理从确定的起始噪声生成结果；各 L2 子级使用上一级输出的裁块放大结果作为粗条件，并使用本层独立的坐标寻址噪声作为起点。
7. 当前 L1 以完整有限域为生成对象。既有相邻窗口在去噪过程中逐步融合的安排保留为后续扩展方案，当前不用于扩大大陆范围。
8. K、D 和其他 LEM 参数只参与 LEM 数据生成、参数验证与结果复现，不进入 L1 或 L2 的训练和推理。

## 14. 已确认的接口风险

### 14.1 同分不同源带来的差异和后果

该 GAP 任务使用 yZz 确定的暂定名称“同分不同源带来的差异和后果”，属于后续 L2 范围，当前暂不开展。

1. `data1000m` 由以 1km 格距模拟为基础的生成方法得到。
2. `data10mds100` 由以 10m 格距模拟为基础的方法形成 `data10m` 后下采样得到。
3. 两类数据的空间分辨率同为 1km，数据来源不同。
4. L1 由原生 1km 数据训练；L2 训练时使用下采样 1km 粗条件；级联推理时使用 L1 实际输出作为粗条件。

任务需要比较原生 1km 数据、下采样 1km 数据和 L1 实际输出，并测量差异对 L2 结果的后果。差异程度、后果和处理方法尚未验证。

### 14.2 LOD 层级映射

当前 E3 负责核对有限大陆 L1 输出与 Distant Horizons 的数据接口、细节等级和尺度转换需求。既有多层模型的分辨率序列及对应关系保留后续身份，验证完成前不声明一一对应。

### 14.3 跨硬件可复现性

坐标寻址噪声可以固定随机输入。浮点执行后端、精度和算子实现仍可能造成跨硬件差异。当前策略不承诺跨硬件逐字节一致，分布式计算验证协议需要另行批准。
