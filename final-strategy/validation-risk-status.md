### 4.1 跨阶段方法与参数验证循环

验证对象是当前方法及其参数配置、方法形成的数据和后续模型结果，并依次形成以下启动假设：

1. 方法所需过程与辅助操作处于工具及项目能力范围内，实施成本处于项目时间范围内。
2. 完整方法形成的数据满足相应训练或验证用途，模拟中间结果符合其承担的操作与通道含义。
3. 方法生成的 `data1000m` 能够训练出符合真实地形要求的高程 L1。
4. 同一方法及相应参数配置生成的数据能够支持高程与汇水面积联合 L1，并达到跨通道一致性指标。
5. 后续范围：方法及参数在 10m 网格中形成 `data10m` 的验证暂不开展，恢复 L2 范围后再安排。

每个假设都有通过和未通过结果。未通过结果形成当前任务，并返回方法来源、辅助操作、参数提取、LEM 设置、模型训练或尺度处理中的对应位置。

### 4.2 方法、数据与模型结果的协议缺口

正式协议至少需要定义以下内容，并区分各指标适用于模拟中间结果、最终训练数据还是模型生成结果：

2. 水文指标，包括汇水面积分布、河网密度、流域结构、洼地和湖泊。
3. 同一大陆内部的地形、地貌和群系覆盖，环境之间的相邻、分隔和连接关系，不同探索方向下的变化，以及各类区域的延伸范围；同时评价样本之间的差异。自然变化没有统一平滑要求，具体指标与可达覆盖范围需要明确。
4. 不同初始条件和随机种子下的稳定性指标。
5. 当前 500 km×500 km、1km 格距 L1 数据中的区域尺度与空间组织指标；10m 及更高分辨率的尺度验证保留后续身份。

## 5. E2 L1 分阶段验证

### 5.1 验证对象

E2 按顺序检查两个 L1 模型版本：

1. 第一个 L1 只生成高程，用于验证当前方法生成的 `data1000m` 能否支持符合真实地形要求的高程生成。
2. 第二个 L1 联合生成高程和汇水面积，用于验证水文生成通道及跨通道一致性。

第二个 L1 的“水文”具体指汇水面积。两个版本都使用 500×500@1km 的 `data1000m`，训练和推理均不接收 K、D 或其他 LEM 参数。两个 L1 阶段通过形成当前验证结果；正式 `data10m` 生产和 L2 数据阶段属于后续范围，不自动启动。

验证模型可以采用较小尺寸，但实验协议必须区分模型容量限制、数据问题、参数问题和方法问题。L1 对 `data1000m` 的拟合程度用于失败归因。

### 5.2 协议缺口

原策略把以下内容混合在一个指标中：

- 从生成高程计算的 D8 汇流结果。
- 模型直接生成的 drainage 通道。
- Terrain Diffusion 高程的后处理结果。
- 填洼后内流盆地数量。

该写法没有形成对称的对照关系。Terrain Diffusion 不直接生成 drainage 通道，因此不能使用与联合模型完全相同的内部跨通道指标。

第二个 L1 开始前需要批准一份完整协议，至少定义：

1. 联合模型内部一致性指标。
2. 与 Terrain Diffusion 的外部比较指标。
3. 边界排水条件和窗口截断处理。
4. 合法内流盆地与生成伪影的区分方法。
5. 样本数量、随机种子、统计方法和不确定性报告。
6. 模型容量控制和失败解释规则。
7. 数据集、代码和模型版本。

流向接收节点索引、上游计算顺序和流量分配索引只用于 LEM 内部汇流计算。流域编号用于验证和统计。`rock_type__id` 用于 Landlab 内部材料管理。这些字段均不进入当前 L1 训练数据。

在协议获批前，旧策略中的“减少 50%”和“提升一个量级”等阈值不用于执行或判定。

## 8. 停止或收缩条件

### 8.1 联合生成方向

若 E2 在已批准协议和容量控制下不能显示联合生成相对于适用基线的改进，则停止水文联合生成产品路线，只保留经验证仍成立的工程方向。

### 8.2 地貌分布

若 E4 显示 LEM 数据产生的地貌分布不能满足已批准的玩家偏好标准，则停止或收缩面向玩家的 LEM 数据产品路线。

### 8.3 LOD 方向

若 E3 显示模型层级与 DH 数据请求之间需要高成本转换，生成式 LOD 方向降级为普通缓存或重采样工程优化。

### 8.4 外部实现

若 Terrain Diffusion 或其他项目发布经过验证的联合水文生成，或发布可直接复用的 TD 与 DH 集成，应重新评估对应工作范围。

## 9. 风险

### 9.1 核心假设尚未验证

联合生成是否能够产生可用的高程与水文一致性尚未由实验确认。E2 负责提供证据。

### 9.2 地貌过程覆盖范围有限

当前 LEM 过程集合主要覆盖流水侵蚀和坡面扩散相关地貌。冰川、喀斯特、火山、风成和其他过程的覆盖程度较低或没有现成组件。该差异可能影响多样性和玩家偏好。

### 9.3 数据接口未完成

当前 L1 仍需明确并验证正式多通道数据格式与训练加载流程。L2 下采样算子与配对数据接口属于后续范围。

### 9.4 工具实现差异

2026-09-03 在 500×500、1 km 格距、dt=1000 年、50 步、单线程、统一参数（m=0.4，n=1，D=0.01 m²/yr，U=0.001 m/yr，K 取 1e-6、1e-5、1e-4）条件下实测，数据与脚本见 `bench/results/L1/`：

| 指标 | 结果 |
|---|---|
| 每步耗时（K=1e-5，三轮中位数） | fastscapelib-fortran 2.8.4 直接 API 70 ms；Landlab 2.10.1 的 PriorityFloodFlowRouter 1988 ms、DepressionFinderAndRouter 9831 ms、LakeMapperBarnes 9895 ms |
| 峰值内存 | fastscape 108 MB；Landlab 444 至 566 MB |
| 差距来源 | 汇流与洼地处理的实现方式；两工具的河道侵蚀与坡面扩散耗时同量级 |
| 洼地处的侵蚀规则 | Landlab 与 fastscapelib-fortran 多流向例程在受水格更高时不更新高程；fastscape 单流向例程未作此判断，见第 9.9 节 |
| Python 操作层 | fastscape 的 xarray-simlab 层在当前环境不可用，见第 9.10 节；Landlab 的 Python 层可用 |
| 洼地处理选项 | Landlab 提供三种组件；fastscape 在 Fortran 内固定一种 |

K 的取值对每步耗时的影响不超过 16%；每次模拟结束时多导出一张汇水面积数组约 3 ms。10 m 网格的性能尚未实测，属于后续范围。数据生产时间估算为每步秒数乘以真实参数下的步数，步数在参数确定前未知。

### 9.5 LOD 映射尚未验证

当前 L1 输出如何对应 Distant Horizons 细节等级尚未验证。既有模型的 10 倍分辨率序列适配属于后续多层模型范围。

### 9.6 跨硬件结果验证尚未定义

坐标寻址噪声可以固定随机输入；浮点后端和精度差异仍可能改变输出。玩家分布式计算在验证协议完成前不能启用。

### 9.7 L3 数据许可和通道接口尚未定义

真实 DEM 或 LiDAR 的许可、L2 过程通道如何进入 L3、L3 输出哪些通道均未形成已批准策略。L3 不进入 MVP。

### 9.8 同分不同源带来的差异和后果

以下风险属于后续 L2 范围，当前暂不开展相应数据生成与实验。以原生 1km 模拟为基础的方法形成的 `data1000m` 与 10m 数据生成后下采样得到的 `data10mds100` 具有相同空间分辨率和不同来源。L1 由前者训练；L2 训练粗条件来自后者；级联推理粗条件来自 L1 实际输出。

差异程度及其对 L2 输出的后果尚未验证。正式任务需要比较三类数据分布，并分别使用训练粗条件与上一级实际输出测试 L2。具体处理方法等待实验结果和后续批准。

### 9.9 fastscape 单流向侵蚀例程的洼地抬升

fastscapelib-fortran 的单流向河道侵蚀例程对受水格高于本格的格子照常执行隐式更新，使洼地底部向受水格高程上升。该上升没有物质来源，并且与其洼地处理算法所依据的论文（Cordonnier、Bovy、Braun 2019，ESurf 7:549，第 3 节）规定的“负坡度按 0 处理”不一致；同库多流向例程含有该判断。2026-09-03 在 2.8.4 版实测确认，并核对了仓库 master 分支 `src/StreamPowerLaw.f90`。后果是 fastscape 生成地形中的洼地消失速度高于 Landlab。处理方案（改用多流向例程、在脚本中于侵蚀后恢复受水格更高格子的高程、修改源码）等待 yZz 选择。

### 9.10 fastscape Python 层不可用

`fastscape` 0.1.0 依赖的 `xarray-simlab` 0.5.0 与环境内 zarr 3.3.0、numpy 2.5.2 存在多处 API 不兼容（2026-09-03 实测：`zarr.MemoryStore` 位置、`Group.create_dataset` 移除、`numpy.in1d` 移除）。fastscape 线当前只能直接调用 fastscapelib-fortran 的 FastScape API。恢复 Python 层需要降级 zarr 与 numpy 或修补 xarray-simlab，两者均需另行授权。

### 9.11 大陆组织与训练尺度

一份 500×500@1km 的 L1 数据能否支持模型生成目标大陆的整体组织、真实感及内部环境多样性，尚未验证。训练样本尺度与可靠生成范围的关系需要模型实验确认，不能从其他模型的使用经历直接确定。当前目标限定为 500 km×500 km 的完整有限海洋大陆，不开展扩大大陆生成范围的研究。

### 9.12 时间步敏感性

2026-09-07 GPT 的实验在同一初始条件下以 50、25、10 kyr 步长演化到同一 4 Ma 时刻，整幅高程均方根差约 20 m，最大绝对差约 150 m，海陆分类不同的格点约 2700 至 3500 个，最高高程几乎不变；原因未查明。该结果来自 Linux 容器中自行编译的部分 FastScape 2.8.4 核心库，多流向指数 1，启用海洋输运，尚未在项目环境复现。yZz 2026-09-08 表述需要查明。过程真实要求的计算可靠性在查明前不成立，输出检验的结论带有数值误差的不确定性。工作线 D 的收敛试验用于查明该差异，见第 4.4 节第 8 项（2026-09-09）。
