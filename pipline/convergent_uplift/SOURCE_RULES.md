# 极值线规则与参数依据

后续完整场阶段采用用户选定的DS5，具体统计、代理映射和数值处理另见[field_pipeline/README.md](field_pipeline/README.md)。本文件以下记录原辅助线阶段。

## 当前范围

用户批准A、B的受约束随机变化，并指定用G统计拟合尺度概率模型。当前处理完整极值线；两侧作用范围、U幅度、年代触发和500km窗口筛选留在对应阶段。直线在此前讨论中用于反例，当前也允许生成低弯曲的简单线形。

## 统计依据

| 对象 | 来源与处理 | 用途与解释 |
|---|---|---|
| 完整尺度 | [G原表](sources/G/landmass-provinces.csv)、[字段定义](sources/G/data_dictionary.md)、[原计算](sources/G/geometry.py) | 筛主34总体及orogenic belt；17行归为15源分区，重复投影测量取中位数。拟合的是完整源几何的最小旋转矩形长边 |
| 曲折及转向参照 | [冻结GEM原件](sources/geology/GEM_pinned_faults.geojson)、[原说明](sources/geology/GEM_README.md) | 筛选汇聚相关类型、至少8顶点、100至5000km、投影长度误差不超过3%的开放简单迹线，保留344条。测量方法与排除数在[tables/geometry_reference.json](tables/geometry_reference.json) |
| 输出尺度映射 | 本项目几何近似 | 抽出的区域长边映射为整张极值线图的外接矩形长边；线条总弧长另算 |
| 曲率代理迁移 | 本项目几何近似 | 将断层/逆冲迹线的尺度化转向用于极值线候选的保守筛选，不解释为U峰值线的观测分布 |

G模型比较lognormal、gamma、weibull及对数尺度KDE。评分均为留一源分区的每km对数预测密度；KDE包含从log-km变回km的雅可比。当前选择log-KDE，带宽约0.122823。正值支持上的尾部属于模型外推。15源分区的比较结果不作为全球代表性结论。不同源分区可能同属相关构造系统，分区之间的统计独立性尚未验证。

GEM每条迹线按弧长重采样257点，以2个采样间隔平滑方向，分别在全长3%、8%、20%的距离上测量方向变化。原始记录、分组分位数及筛选条件全部保存。

## 地学形态参照

1. Livani等2018的北亚平宁逆冲前缘具有相邻凸出与凹入结构，支持长缓弯、反向弯曲和局部变化共存的形态参照。[原研究](https://doi.org/10.1002/2017JB015235)。本轮采用其结构解释，不从摘要生成数值分布。
2. Davis等2005的Ostler逆冲系统描述重叠、错列和不重叠的段间关系。[原PDF](sources/geology/Davis2005_Ostler.pdf)，DOI 10.1016/j.jsg.2005.04.011。部分所测段只有数百米，当前借用组织方式；代码的km尺度和段长比例保持设计身份。
3. Harvey等2015描述西尼泊尔约150km范围内单前缘向双前缘变化的构造解释。[原PDF](sources/geology/Harvey2015_Nepal.pdf)，DOI 10.1130/L444.1。用于允许局部分开和重汇合的案例依据，不推导全球分叉频数。
4. 用户提供的六图原型给出实际程序化界面形状。[原ZIP](sources/prototype/convergence_axes_6_examples.zip)、[原对话](sources/prototype/conversation.md)、[原脚本](sources/prototype/generate_axes.py)。当前改造保留其竞争界面作为曲线来源，并以有限停止代价解决完整端点问题。

## 本版规则

| 规则 | 检查方法 | 依据身份 |
|---|---|---|
| 完整终止 | 所有竞争前沿在辅助域内部停止，保留模型定义的自由端点；不作500km裁切 | 任务要求及算法实现 |
| 坐标与连接 | 坐标有限、步长正、端点精确共享；间断与同节点对的多条路径保留 | 几何表示正确性 |
| 相交 | 单边不自交，边间相交只发生在声明的节点 | 本版允许结构的设计规则 |
| 曲折度 | 上限为1＋3×（代理迹线p99曲折度－1），约1.6974 | 实测代理分位数＋设计放宽系数；保留比大多数断层迹线更弯曲的候选 |
| 多尺度转向 | 8%、20%长度尺度上的p95转角不超过代理相应p99的1.65倍，并限于175度内 | 实测代理＋设计放宽系数 |
| 极短边 | 每条边弧长至少为整张曲线图长边的4.5% | 本版几何分辨与结构尺度设计 |
| 连接可辨识 | 三度节点相邻边短距离方向夹角至少12度；自由端点与非关联边至少相隔整体长边的1.8% | 几何表示设计，避免未连接端点在图上表现为连接 |
| 非连接处近接 | 排除共享节点周围6%尺度邻域后，其他边至少相隔整体长边的0.8% | 几何表示设计；不作为自然构造绝对下限 |
| 分段与回路组合 | 分段只处理桥边，保持已有回路和共享节点；允许多个不相连的片段同属一个生成对象 | 本版结构组合规则 |

这些阈值在正式种子运行前固定。几何和代理检查通过表示符合本版规则；yZz于2026-09-17确认汇聚模块完成并验收，代理与设计参数的依据身份继续按本文件保留。

## 随机分布与内部参数

全部设计参数保存在axis_generator.py的DESIGN及每个输出JSON中。主要次数分别为截断泊松分布：分支λ=0.85、上限3；局部重汇合λ=0.40、上限2；错列分段λ=0.65、上限3。零次操作均有正概率，三个次数先独立抽样，之后按几何兼容性接受或拒绝。

分支长度比例0.13至0.34、相对出发方向28至76度；段间有符号间隙比例-0.035至0.045，负值允许沿线重叠；侧向错列比例0.009至0.030。以上均为试验设计分布，结合所列案例组织方式使用，没有伪装为地质统计。

竞争代价使用不同尺度和方向的随机波动、随机局部变化及空间非均匀强度。低变化强度有正概率。算法代价、传播上限和局部曲线的相似变换不具有构造时序或运动速率含义。

每个种子固定抽取一个G尺度，几何重试不会重新抽尺度。结构不相容的候选被拒绝，原因和原计划保留。接受分布因此受到明确几何条件影响；没有读取其他已生成样本来提升稀有类别的概率。

## 调试记录

独立测试使用9001至9004，与正式1001至1016分离。第一组中发现支线端点与其他边过近、容易在图上误认连接；加入上述近接检查后重新核对测试结果。research/pilot_batch保留前一版本，research/pilot_clearance保留修正版本。正式参数不按16个最终样本的类别数量调整。
