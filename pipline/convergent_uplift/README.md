## 生成顺序

1. 读取G的主参考总体中17条造山带记录，按完整源分区归为15个不同源分区。重复源分区的不同局部投影结果取中位数，各源分区等权。
2. 比较正值分布及对数尺度核密度模型，用留一源分区检验选择模型。按样本种子抽取完整区域最小旋转外接矩形长边，单位km。
3. 使用有限的区域种子组及最大累计传播代价生成完整竞争界面。外围保留未占据区域，界面在内部终止；活动前沿触及辅助域时扩大辅助域。空间代价由连续多尺度随机场和随机局部变化共同确定。
4. 对完整主线进行随机结构操作。局部支线同样来自有限竞争界面，通过等比旋转缩放和平移定位，再以共享节点连接；重汇合保留同一对节点间的两条路径。分段改变间隙、重叠、错列和段内方向，保持原共享节点。
5. 按声明的规则拒绝几何不相容的候选，并保留每次原因。分段和连接操作可以为零；没有固定六类配额或按稀有类别补样的机制。
6. 对整个最终曲线图统一作一次等比尺度映射，使其最小旋转外接矩形长边等于G抽样值。总弧长、分支长度和节点坐标据此计算。完整原比例坐标输出，不裁取500km窗口。

第4步采用明确的图结构组合来开放多次分叉与混合结构。它属于对用户提供原型的改造；原型的三区域交汇实现完整保存在sources/prototype中。

## 模型与数据含义

尺度模型的变量是完整造山区域的外接矩形长边，弧长另列。将区域长边用于完整极值线长边，属于本项目几何近似。

几何参照从冻结GEM原件中筛选Reverse、Subduction_Thrust、Blind Thrust，统一投影及测量后保留344条迹线。它们用于多尺度转向和曲折度的代理参照。断层迹线与U峰值线的对应保持近似身份。

弯曲场内部权重、局部变化位置、分支和分段次数、错列及几何可分辨阈值采用明确的设计分布。当前没有把这些参数称为真实构造频率。详见SOURCE_RULES.md。

## 输出结构

每个正式种子生成PNG、SVG、JSON、CSV。JSON保存全部几何边、节点编号、各边与节点的关联、尺度抽样、结构计划、生成来源、重试记录与程序哈希。坐标为局部笛卡尔km；接入其他单位时应显式换算。

每张图片使用实际km刻度和等比例坐标轴，自适应显示完整线形。实心点为自由端点，空心点为共享连接点。不同图片的取景范围随完整尺度变化。

research目录保存正式输出前的调试种子和问题记录；正式交付仅为output目录的1001至1016。sources保留冻结资料，本轮未改动项目其他生成模块。
