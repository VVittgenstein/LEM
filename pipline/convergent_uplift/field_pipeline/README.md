# DS5约束的完整二维抬升场

本模块在已有完整辅助极值线的基础上，拟合U取值、空间相关性、两侧宽度与下降曲线形态，生成完整二维抬升场。主数据采用用户选定的DS5。所有代码、来源副本、模型、试运行和正式产物均位于本目录。

入口：[8组A/B图集](output/gallery.html)、[交付记录](output/delivery.md)、[PNG压缩包](output/eight_pairs_png.zip)。可用父目录的`run_fields.ps1`重跑。此前16份辅助线单独保存在父目录output，本次按种子1001至1008重新运行同一辅助线生成器。

## 数据与拟合

| 对象 | 输入与测量 | 拟合输出 |
|---|---|---|
| U取值 | DS5第8列GNSS参考后的垂向速率，单位mm/yr；按剖面提取正向峰值 | 正值分布比较，留出20 km空间区块评分，当前选择log-KDE |
| 沿线空间变化 | 峰值序列的正态分位数，不同距离的半方差 | 平稳相关模型，距离单位km |
| 两侧不对称 | 同一剖面的NW、SE拟合半高宽 | 比例Beta分布；与两侧形状参数的联合正态分位数相关 |
| 横向下降形态 | 实际支持位置上的U/峰值与距离 | 对每个单侧剖面拟合Weibull、log-logistic，线性作对照；拟合半高宽及形状指数 |
| 完整宽度尺度 | G主总体15个去重源分区，完整长边与面积/长边配对 | 二维对数KDE，条件于已生成辅助线的长边抽取等效宽度 |
| 沿线宽窄变化 | 15个完整多边形沿最小旋转矩形长轴的129个截面 | 相对宽度的正值分布及归一化距离相关模型 |
| 头尾长度 | G几何端点至首次达到中央代表宽度一半的位置 | 距离/等效宽度的正值分布，作为辅助线端部扩展的几何代理 |

原件及哈希见[sources/manifest.json](sources/manifest.json)。DS5来自[McGrath数据集](https://zenodo.org/records/15541458)，论文DOI为10.1029/2024JB030625。G沿用Hasterok固定提交6cdcbf021178e9adf65e7f9c3d77c5497a976bf4及既有测量定义。Herman原文只作为强区与较弱外围结构的参照，未把其数值混入DS5拟合。

DS5有12,089条记录，参考垂向速率及误差列完整。经纬度取到百分之一度，存在1,042条重复坐标记录；同坐标按误差加权合并，误差保留组内离散，不按记录数缩小。原始负值完整保留。坐标转换为NZTM局部km，以正向高值区的主方向建立参考剖面；横向坐标的NW/SE命名只适用于参考区。

参考场采用沿带4 km、横带3 km的误差加权局部平均，每5 km提取剖面，横向采样2 km。来源间隙大于5 km或有效支持不足的部分标为缺测。最终取得33个峰值、63个单侧下降剖面、25组双侧半高宽。这些是一个案例内的相关空间观测，不能解释为33次独立活动。

详细输入、筛选、每侧拟合结果及原归一化数据保存在models/DS5_profiles.json、DS5_decay_fits.csv、DS5_reference.npz。总体形态族的比较为参考剖面的重建误差；概率分布族比较使用空间区块留出，二者分别记录。

## 生成与有限边界

用种子生成连续潜在正态场，再通过拟合分布的分位数函数转换成U、宽度及形状参数。384个随机傅里叶分量用于近似拟合协方差；在同一物理坐标处取相同值，连接节点不独立重抽。G宽度相关距离随完整长边缩放；DS5相关距离保留km单位，低于5 km的拟合尺度以原剖面采样尺度作为生成下限。对远超参考区的长度采用同一统计模型属于外推。

辅助线上的U已有连续随机强弱变化。横向随机性由拟合形状参数产生。参考剖面使用`exp(-ln(2)*(d/H)^p)`，H为半高宽，p控制下降快慢的变化。两侧p分别来自各自的拟合分布，和半高宽比例保留联合统计，再转换为有限作用宽度比例。

精确零边界采用显式计算约定：比较5%、10%、15%、20%、25%、30%候选参考水平，选取至少80%支持剖面可达到的第一项。本批为25%，63条中51条达到。该约定截去并归一化较弱尾部，不能解释为观测证实外围抬升正好为零。先由拟合函数确定曲线，再用2%归一化距离的中心正则化消除尖导数；最后10%距离使用单调Hermite曲线接到零值、零斜率。原曲线、处理规则与生成曲线分别可查。

G完整区域的等效宽度为面积除以最小旋转矩形长边。生成时对各部分宽度作一个共同尺度校准，使整个支持范围并集按同一定义回量后接近本次抽样目标。1 km实际数组上的误差另外保存。G区域包含地质历史信息，将其作为单次活动范围属于几何代理。

左右以各有向几何边的法向定义。全样本可随机镜像一次，概率各半为未指定板块极性时的对称设计。头尾扩展长度由G端部代理抽样，纵向使用两侧形状指数的几何均值衰减，横向支持在端部连续收窄。端部U衰减形式属于实现假设。

## 二维计算与连接

二维计算以辅助线的距离及参数为依据。线参数向外延伸时，用相邻线采样点的连续归一化权重插值：在线附近基准平滑尺度4 km，距辅助线的距离乘0.3后与基准尺度作平方和开方，最多96个邻点，邻域外缘权重连续降为零。该距离相关平滑是二维插值规则，用于避免最近位置切换产生接缝；它会改变最终场中的局部统计，因此保存实际回读结果。

单侧距离相对于当地生成宽度归一化后代入下降函数。头尾将共同纵向衰减与两侧横向衰减相乘，避免两侧形状不同导致端部中线接缝。多个几何部分重叠时取各自贡献的最大值，保持连续数值和有限支持；交汇处的梯度可存在折线。这是同一次活动的合成规则。

辅助线用作生成约束。二维插值和重叠可能使实际沿线值与输入不同，输出actual_axis_statistics.json及总体统计图明确显示差异。所有数组保持原物理尺度，没有500 km裁切或缩放。

## 图片与文件

- 每个种子保存A.png、B.png、成对pair.png及A/B SVG。两个视图共用8英寸画布、170 dpi、同一绘图区和坐标变换。
- B使用冻结的查看器`PALETTES['fem']`及其12级分段颜色。8个样本共用一个数值色标。外部零值也使用最低色阶，白色虚线标出实际支持范围。
- field.npz保存x_km、y_km、u_m_per_yr及support。格距1 km，y随数组行号增加；图像origin为lower。
- axis.json保存完整辅助线原坐标。A/B直接读取同一份数据，SVG辅助线路径逐条比较。
- axis_field_parameters.json保存抽样曲线参数；metadata.json保存抽样、尺度校准、实际范围和哈希。
- SVG的场使用嵌入栅格，辅助线、坐标和色标保留矢量。PNG为直接渲染图。
